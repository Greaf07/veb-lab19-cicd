НА ЭТОМ КОМПЬЮТЕРЕ
В PowerShell:
  cd "C:\Users\kirpo\OneDrive\Desktop\PSU\5 sem\VEBTEXNOLOGII\lab9"
  npm.cmd run cloud:start

Команда запускает отдельный workflow cloud.yml, ждёт его завершения
и показывает ссылку на журнал. В Summary находится HTTPS-адрес приложения.
Workflow включает Codespace, запускает сохранённые контейнеры и проверяет
/health. Полная сборка и npm install для такого включения не нужны.
Очередь GitHub и пробуждение среды могут занять некоторое время;
лучше включить лабораторную за 5–10 минут до показа.

ПОСЛЕ ЗАЩИТЫ
  npm.cmd run cloud:stop
Остановка сохраняет файлы и PostgreSQL. Не удаляйте Codespace или папку
/workspaces/lab19-cloud, если хотите сохранить учебные данные.

БЕЗ ТЕРМИНАЛА
GitHub -> репозиторий veb-lab19-cicd -> Actions ->
Start or stop lab19 for defense -> Run workflow -> action: start.
После показа повторить с action: stop.

ДЛЯ АССИСТЕНТА ПРИ СЛЕДУЮЩЕМ ОБРАЩЕНИИ
1. Прочитать Проверка.txt и Защита.txt в lab9.
2. Выполнить npm.cmd run cloud:start в папке lab9 с сетевым доступом.
3. Дождаться успешного workflow, открыть его Summary и /health.
4. Проверить status=ok и database=connected; показать пользователю ссылку.
5. Не пересобирать приложение и не создавать новый Codespace без причины.
6. Если нужен локальный резерв: запустить Docker Desktop и npm.cmd start;
   адрес локальной копии http://localhost:3006/health.

ПОДКЛЮЧЕНИЕ С ДРУГОГО КОМПЬЮТЕРА
Нужны Node.js и GitHub CLI (https://cli.github.com/), вход gh auth login
в аккаунт владельца. Затем команда cloud:start из папки исходников.
Для включения через сайт GitHub локальные программы вообще не нужны.

ОГРАНИЧЕНИЯ
Codespaces — учебная облачная среда. При простое она останавливается;
поэтому ссылка работает только после включения окружения.
Проверенный срок хранения остановленной среды — 30 дней.
Срок токена и состояние среды ещё раз проверить перед защитой.
Токен автоматизации создан со сроком до 28 ноября 2026.
Для живого показа API: npm.cmd run cloud:demo.
